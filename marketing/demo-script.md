# Demo script (60–90 seconds)

1. Open the public demo and point out the permanent mock-mode banner.
2. Choose “Structured extraction”.
3. Leave four simulated targets enabled and click Run comparison.
4. Show response cards filling independently while stream event counts grow.
5. Open Metrics and call out TTFT, total duration, tokens and estimated cost labels.
6. Open Compatibility and show native/adapted/partial states.
7. Enable Strict compatibility, select the incompatibility preset and run again to show a blocked target.
8. Open Native request, then Raw response.
9. Export the sanitized JSON report and explain that no API keys or private content are included by default.
10. Point to “Local gateway · real keys” and explain that real execution is local only.
