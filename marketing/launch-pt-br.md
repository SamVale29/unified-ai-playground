# Post de lançamento — Português

As APIs de IA são fragmentadas de um jeito que o texto final não consegue explicar. “Compatível” pode significar roles diferentes, schemas de tools diferentes, garantias diferentes de JSON, eventos de streaming incompatíveis ou contabilidade de tokens distinta.

O AI SDK Playground é um laboratório open source e local-first que executa o mesmo experimento normalizado em OpenAI, Anthropic, Google Gemini, xAI, DeepSeek, Mistral AI e OpenRouter. Ele mostra o request do usuário, a IR, as transformações do adapter, o payload nativo e as respostas lado a lado.

A demo pública usa providers simulados e determinísticos, não pede API keys e não faz proxy de inferência. Chamadas reais passam por um gateway local controlado pelo desenvolvedor. O projeto aceita adapters comunitários, relatórios de compatibilidade e fixtures reproduzíveis.
