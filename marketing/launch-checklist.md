# Launch checklist

- [ ] Run `pnpm format:check`, lint, typecheck, catalog validation and tests.
- [ ] Run the mock E2E flow on desktop and mobile.
- [ ] Run the secret scanner and inspect the diff.
- [ ] Confirm `.env` and raw auth headers are absent.
- [ ] Build the public demo with `VITE_PUBLIC_DEMO_MODE=true` and the repository base path.
- [ ] Configure GitHub Pages, Discussions, Issues, security features and branch protection.
- [ ] Create six to ten real follow-up issues with acceptance criteria.
- [ ] Publish the v0.1.0 release notes and link the demo.
