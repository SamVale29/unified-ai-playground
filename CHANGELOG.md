# Changelog

## 0.1.0 — 2026-08-03

- initial open-source multi-provider playground;
- source-linked seven-provider catalog and adapter packages;
- provider-neutral experiment IR and compatibility transformations;
- deterministic public mock mode;
- local Hono gateway with SSE, timeout, cancellation and redaction;
- React/Vite comparison UI with metrics, inspector, export/import and security panel;
- CLI, contract/unit/integration/E2E scaffolding, CI and GitHub Pages deployment.

Known limitations are documented in [`docs/known-differences.md`](docs/known-differences.md).
