# Roadmap

## v0.1

- seven first-class provider adapters;
- text comparison, mock streaming, tools and structured-output validation;
- local gateway, CLI, export/import and compatibility report;
- public mock demo and secure CI.

## v0.2

- dataset runner and batch experiments;
- human evaluation and more media fixtures;
- dynamic model discovery and richer cost registry;
- prompt templates and adapter plugin API.

## v0.3

- Git-based experiment storage;
- provider conformance reports;
- browser extension and optional desktop packaging.

## Future

Python SDK, self-hosted remote gateway, Kubernetes deployment, OpenTelemetry dashboards, MCP tool testing and audio/realtime comparison.
